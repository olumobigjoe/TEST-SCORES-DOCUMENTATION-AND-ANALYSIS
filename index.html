Features

Everything built in,
nothing to configure

Name-based login
Students enter their full name to begin. No passwords, no accounts — simple and frictionless access.
Randomised questions
30 questions drawn randomly from a bank of 39 per session. Option order is also shuffled — every student sees a unique exam.
10-minute countdown
A live timer runs throughout the session. When it expires, the test auto-submits and the score is computed instantly.
Instant feedback
After confirming each answer, the student sees "Correct" or "Wrong" immediately — without the correct answer being revealed.
Anti-cheat device lock
Each browser session is fingerprinted and stored. Re-attempts from the same device are permanently blocked.
Live score board
A real-time results table sits on the login page and updates as each student completes the test.
Pass / fail result
The result page displays percentage, correct count, and a clear PASS or FAIL banner. Pass threshold is 65%.
CSV export
Every submission is appended to scores.csv with name, score, timestamp, and pass/fail status.
Responsive UI
Streamlit's layout adapts cleanly to desktop and tablet. No extra CSS or media queries needed.
How it works

Student journey,
step by step

Student enters full name

02
Questions shuffled and served
30 questions are drawn at random from the 39-question bank. Both the question order and the three options for each question are independently shuffled. A 10-minute countdown starts immediately.

03
Student selects and confirms each answer
Option buttons highlight the selection. The student then clicks "Confirm Answer" to lock it in. Feedback — Correct or Wrong — appears immediately. The correct answer is never shown.
st.session_state
04
Auto-submit on time expiry
If the 10-minute timer reaches zero, finish_test() is called automatically. Unanswered questions count as incorrect.

05
Score displayed and saved
The result page shows the percentage, correct count out of 30, and PASS / FAIL. The row is appended to scores.csv and immediately visible in the live score board on the login page.

Code

Core logic

glt302_quiz.py 
# ── Session setup: randomise questions once per student ───────────────
def prepare_session(name, device_id):
    pool = ALL_QUESTIONS.copy()
    random.shuffle(pool)                    # unique order per student
    selected = pool[:NUM_Q]                  # pick 30 from 39

    for q in selected:
        opts = q["options"].copy()
        random.shuffle(opts)                 # shuffle option order too
        q["shuffled_options"] = opts

    st.session_state.questions  = selected
    st.session_state.start_time = time.time()
    st.session_state.name       = name

# ── Anti-cheat: one attempt per device ────────────────────────────────
def check_and_lock(device_id, name):
    data = load_attempts()              # reads attempts.json
    if device_id in data:
        st.session_state.page = "blocked"
        return False
    data[device_id] = name              # fingerprint this device
    save_attempts(data)
    return True

# ── Timer: auto-submit when time expires ──────────────────────────────
remaining = max(0.0, DURATION_SEC - (time.time() - st.session_state.start_time))
if remaining <= 0:
    finish_test()   # compute score → save CSV → go to result page
    st.rerun()

Configuration

Easy to customise

All settings live at the top of glt302_quiz.py — no config files needed.

ConstantDefaultWhat it controls
DURATION_SEC 600 Test duration in seconds (600 = 10 minutes)
PASS_MARK 65 Minimum percentage required to pass
NUM_Q 30 Number of questions served per session
SCORES_CSV "scores.csv" Output file path for results
ATTEMPTS_JSON "attempts.json" Device fingerprint store (delete to reset attempts)
Setup

Running in
four steps

1
Clone the repository
Download the project to your local machine.
git clone https://github.com/yourusername/glt302-quiz-system.git cd glt302-quiz-system
2
Install dependencies
Only two packages required.
pip install streamlit pandas
3
Run the app
Streamlit opens the app in your browser automatically.
streamlit run glt302_quiz.py
4
Share with students
Share the Network URL with students on the same Wi-Fi — or deploy to Streamlit Cloud for a public link.
Local URL: http://localhost:8501 Network URL: http://192.168.x.x:8501
Reset between exam sessions
Delete the auto-generated data files to clear all attempts and scores.
rm attempts.json scores.csv
